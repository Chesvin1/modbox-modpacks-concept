# Modbox — Modpacks concept

A static HTML mockup of the proposed Modpacks catalog in Apex Hosting's Modbox, matching the supplied panel screenshot. Intended as a visual reference for the Confluence proposal.

Open `index.html` directly in a browser. No installation or build is required. The repository root is also ready to serve with GitHub Pages.

Category and loader checkboxes, category collapse, and sort/version dropdowns can be selected. They do not filter or sort the fixed catalog. Search, resource tabs, navigation, pagination, and modpack rows are visual examples only. Nothing installs a modpack or connects to a server.

All catalog counts, download figures, dates, and versions are illustrative sample content. The proposal document was not modified as part of this mockup.
